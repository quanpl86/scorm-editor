QUESTION TYPES ONLY: MC, MR, TF, MG, SEQ, FIB, TI, NUM, MNUM.

ANSWER RULES:

- MR: two or more answers prefixed with *
- TF: * on the correct of Đúng/Sai (or True/False). Only Answer 1 and Answer 2. Answer 3–6 EMPTY.
- MG: "Left|Right" per Answer N; no *; max 6 pairs
- SEQ: Answer 1..N in correct order; no *; max 6 steps
- NUM: single number in Answer 1 only
- MNUM: numbers in Answer 1..K in required order

=== TI / FIB — NHIỀU ĐÁP ÁN TƯƠNG ĐỒNG (CRITICAL — hay lỗi TSV) ===

ƯU TIÊN CÁCH A — nhiều cột Answer (Use Regex = False):
  Answer 1 = đáp án chính (plain text, KHÔNG * )
  Answer 2, Answer 3, … = từ đồng nghĩa / biến thể (mỗi biến thể 1 cột, tối đa Answer 6)
  Explanation = giải thích sư phạm (cột riêng SAU Answer 6)
  Use Regex = False
  Example TI:
    Answer1=BrickColor | Answer2=Color | Answer3=Màu sắc | Explanation=... | Difficulty=medium | … | Use Regex=False

CÁCH B — một biểu thức RegEx (Use Regex = True) — chỉ khi thật sự cần:
  Answer 1 = TOÀN BỘ regex, đúng 1 ô, ví dụ: ^(?i)(BrickColor|Color|Màu sắc)$
  Answer 2 … Answer 6 = BẮT BUỘC ĐỂ TRỐNG
  Explanation = cột Explanation (không nhét vào Answer)
  Use Regex = True
  Required = True/False

CẤM (gây lệch cột / CMS sai):
- Gộp đồng nghĩa bằng dấu | trong Answer 1 khi Use Regex=False  (SAI: BrickColor|Color)
- Gộp đồng nghĩa bằng dấu phẩy trong một ô Answer khi Use Regex=False
- Đặt regex vào Answer 1 mà Use Regex=False
- Đặt Use Regex=True mà vẫn điền Answer 2..6
- Nhét Explanation / Difficulty / Topic vào cột Answer
- Dùng dấu * trên TI/FIB (không dùng * cho short answer)
- Xuống dòng hoặc TAB bên trong bất kỳ ô nào
- Đếm thiếu TAB giữa các cột (mỗi hàng PHẢI đủ 35 cột = 34 ký tự TAB)
